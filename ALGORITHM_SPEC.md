# Svaha2 Core Algorithm Specification & Status

This document outlines the core algorithm for constructing variation graphs from a reference genome and VCF variants, updated with modern algorithmic advancements (2019-2026).

## 1. Algorithm Overview [STATUS: COMPLETED]

The construction follows a **breakpoint-based discretization** approach:
1.  **Breakpoint Identification**: Extract all genomic positions where a variant starts or ends, plus regular intervals to satisfy a maximum node size.
2.  **Reference Discretization**: Sort and uniquify these breakpoints to divide the reference into a series of non-overlapping "backbone" nodes.
3.  **Graph Construction**: Iterate through the backbone, emitting reference nodes and edges, then overlay variant-specific nodes and edges based on the VCF.

---

## 2. Phase 1: Breakpoint Calculation [STATUS: COMPLETED]

Breakpoints are 0-based coordinates on the reference genome.

### 2.1 Variant Breakpoints [STATUS: COMPLETED]
For each variant at `POS` (1-based) with reference allele `REF` and alternate allele `ALT`:
- **Start Breakpoint**: `start = POS - 1`
- **End Breakpoint**: 
    - **SNPs/Indels/MNPs**: `end = POS - 1 + len(REF)`
    - **Structural Variants (SVs)**: Extracted from the `END` INFO tag.
    - **Insertions (INS)**: `end = start` (single breakpoint).
- **Interchromosomal (BND/TRA)**: Breakpoints at `start` on `CHR1` and the corresponding position on `CHR2`.

### 2.2 Global Breakpoints [STATUS: COMPLETED]
- **Max Node Size**: Insert a breakpoint every `N` base pairs (default 32) along each contig to ensure no node exceeds the size limit.
- **Contig Boundaries**: Always include `0` and `contig_length`.

### 2.3 Finalization [STATUS: COMPLETED]
1. Collect all breakpoints into a per-contig list.
2. Sort the list numerically.
3. Remove duplicate positions.

---

## 3. Phase 2: Graph Generation [STATUS: COMPLETED]

The graph is generated by iterating through the sorted breakpoints $B_i$ and $B_{i+1}$ for each contig.

### 3.1 Reference Backbone [STATUS: COMPLETED]
For each interval $[B_i, B_{i+1})$:
1. **Create Node**: Extract reference sequence from $B_i$ to $B_{i+1}$.
2. **Emit Node**: Assign a unique ID and output as a GFA `S` line.
3. **Connect Backbone**: Add a GFA `L` line from the node at $[B_{i-1}, B_i)$ to the current node.
4. **Index**: Maintain a mapping of `(contig, position) -> node_id` for variant attachment.

### 3.2 Variant Overlay [STATUS: COMPLETED]
Variants are processed by connecting existing backbone nodes or adding new alternate nodes.

| Variant Type | Graphical Mode Logic | Status |
| :--- | :--- | :--- |
| **SNP / MNP** | Create alt node with `ALT` seq. Edge: `pre -> alt -> post`. | COMPLETED |
| **Deletion** | Edge: `pre -> post` (skips deleted backbone nodes). | COMPLETED |
| **Insertion** | Create alt node with `ALT` seq. Edge: `pre -> alt -> post`. | COMPLETED |
| **Inversion** | Edge: `pre -> end_node` (T-T) and `start_node -> post` (H-H). | COMPLETED |
| **Translocation**| Edge from `pre` on `CHR1` to `post` on `CHR2`. | COMPLETED |

## 4. Modern Improvements & Algorithmic Breakthroughs (2019-2026)

### 4.1 Bubble Normalization & Variant Minimization [STATUS: RECOMMENDED]
- **Improvement**: Implement a **normalization step** before graph construction. Use a tool like `bcftools norm`.

### 4.2 Handling Nested Variation [STATUS: PARTIAL]
- **Improvement**: Use a **segment-tree** or **interval-tree** to manage variants. (Current: Discretized breakpoints).

### 4.3 Path-Based Indexing (GBWT/GBZ) [STATUS: COMPLETED]
- **Improvement**: Emit GFA 1.1 `W` (Walk) lines or `P` (Path) lines. (Current: GFA 1.1 compatible).

### 4.4 Reference-Neutral Construction (Minigraph Logic) [STATUS: COMPLETED]
- **Improvement**: Adopt **Minigraph's "stable coordinate"** idea. (Current: `SN/SO/SR` tags implemented).
